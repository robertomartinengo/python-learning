# Python Learning

Welcome to my personal repository. This project tracks my technical skills, software development progress, algorithms, and desktop applications written in Python.

## Projects Included

### 1. 📋 To-Do List Application (`todo-list-gui`)
A full desktop task management GUI built with Tkinter.
* **Architecture:** Advanced GUI handling using dictionaries, independent task frames, and dynamic layout refreshing (`pack_forget` for priority sorting).
* **Key Concepts:** CRUD operations, state persistence, custom widgets (`Combobox`, `Checkbutton`).
* **Note:** High-school end-of-year **group project** (**May 2026**), achieved top marks (**10/10**). Acted as the technical lead for the team.

### 2. 🏦 Bank Account Management Application (`bank-account-gui`)
A desktop GUI application built with Python and Tkinter for basic bank account operations.
* **Architecture:** Object-Oriented Programming (OOP) design separating business logic (`Conto` class) from the Tkinter GUI (`Finestra` frame).
* **Key Concepts:** Encapsulation (`__saldo`), GUI layout management (`grid_forget`), and event handling.
* **Note:** High-school classroom project (**April 2026**).

### 3. 🎯 "Trova Calogero" (`battleship-variant`)
A modular Command-Line Interface (CLI) Battleship variant game written in Python.
* **Architecture:** Modular structure cleanly split into a custom module (`funzioni_trova_calogero.py`) and main execution flow (`main_trova_calogero.py`).
* **Key Concepts:** 2D matrices/arrays, random target placement, input validation, and functions.
* **Note:** High-school end-of-year **group project** (**May 2025**), achieved top marks (**10/10**). Acted as the technical lead for the team.

Upcoming algorithms and scripts focused on algorithmic problem solving, data processing, and quantitative financial analysis.
