# 🎯 "Trova Calogero" (Battleship Variant)

A modular Command-Line Interface (CLI) game written in Python where the player tries to find "Calogero" on a customizable grid. 
Developed as a high-school end-of-year **group project** (**May 2025**), achieving top marks (**10/10**). I acted as the technical lead for the team, personally handling the core architecture and development.

## Features
* **Modular Architecture:** Logic and execution flow are cleanly separated into a custom module (`funzioni_trova_calogero.py`) and a main script (`main_trova_calogero.py`).
* **Dynamic Grid:** 2D matrix manipulation based on customizable user input.
* **Game Logic:** Random placement of the target, input validation, and tracking of remaining attempts.

## Project Structure
* `main_trova_calogero.py`: Game loop, input handling, and flow control.
* `funzioni_trova_calogero.py`: Grid creation, rendering, and target positioning logic.

## Technologies Used
* **Language:** Python 3
* **Core Concepts:** 2D Matrices/Arrays, Control Flow (`while`/`for`), Functions, Input Validation
